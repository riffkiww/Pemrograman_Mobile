### 🔑 SOAL NOMOR 1 

Proyek aplikasi mobile ini dikembangkan menggunakan **Flutter** (Bahasa Dart). Struktur aplikasi dirancang menggunakan arsitektur *Single Activity* dengan **lima Fragment** (diimplementasikan sebagai *Widget* terpisah) yang diatur oleh **Bottom Navigation Bar**.

Sesuai SubCPMK 2, aplikasi menerapkan berbagai jenis *layout* dan *widget* kunci:
1.  **Layout & Navigasi:** Menggunakan `Scaffold` untuk struktur utama, `SingleChildScrollView` untuk halaman form, dan `BottomNavigationBar` untuk navigasi antar Fragment.
2.  **Widget Input:** Halaman Biodata menggunakan `TextFormField`, `DropdownButtonFormField`, `RadioListTile`, dan fungsionalitas `showDatePicker` (Calendar).
3.  **Tampilan Berulang:** Halaman Kontak dan Berita menggunakan `ListView.builder` untuk menampilkan data statis secara berulang dalam pola *Card* yang elegan.
4.  **Fungsionalitas:** Halaman Kalkulator mengimplementasikan logika perhitungan dasar (tambah, kurang, kali, bagi, kuadrat, akar kuadrat).
